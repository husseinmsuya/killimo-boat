# 🌾 AgriAdvisor AI

AgriAdvisor AI is an intelligent agriculture assistant powered by Retrieval-Augmented Generation (RAG) and AI technologies.  
The system helps farmers and agriculture stakeholders access accurate farming information through a smart chatbot interface.

---

## 🚀 Features

✅ Crop recommendations  
✅ Plant disease guidance  
✅ Fertilizer recommendations  
✅ Irrigation advice  
✅ Pest management support  
✅ Region-based farming information  
✅ Agriculture FAQ assistant  
✅ AI-powered semantic search using FAISS  

---

## 🧠 AI Technologies Used

- Python
- Flask
- FAISS Vector Database
- Retrieval-Augmented Generation (RAG)
- NLP Embeddings
- HTML/CSS Frontend
